مرصد النتائج المدرسية — دليل المطور 6.9.17

1. ملفات التشغيل النهائية في جذر المشروع.
2. مصدر التطوير داخل source/.
3. source/base/app.js هو bundle الأساس المطلوب للبناء الحالي؛ لا تحذفه حتى تتم إعادة التطوير الكاملة إلى React/TypeScript.
4. source/src/ يحتوي الخدمات الحالية: المحرك، الكتالوج، الهيكل الأكاديمي، السحابة، التقارير، الفلاتر، والتجميع.
5. source/src/patches/ يحتوي Patches لازمة للبناء الحالي، وليست نسخًا قديمة مستقلة.
6. source/db/schema.sql مرجع إنشاء قاعدة جديدة، وsource/db/migrations/ ترحيلات لازمة للبيئات القائمة.
7. الاختبارات الحالية داخل source/tests/؛ نواتج الاختبارات لا تُحفظ في المستودع.
8. بعد أي تعديل: build ثم regression ثم report logic ثم cloud ثم structure ثم release ثم release tests.
9. لا تضع service_role أو Secrets داخل ملفات الواجهة.
10. الإصدار الحالي 6.9.17 وWorkspace Schema الحالي = 7.
