تقرير اختبارات مرصد النتائج المدرسية — Cloud v6.8.0

النتيجة النهائية:

أهم اختبارات 6.8.0:
- ترحيل بيانات 6.7.x تلقائيًا إلى Workspace Schema 7 مع اشتقاق الصفوف والشعب والمواد من البيانات الحالية.
- رفع نتيجة بلا اسم معلم وربطها تلقائيًا بالمعلم الصحيح من المادة + الشعبة.
- تغيير معلم خلية في خريطة التكليفات يستبدل التكليف دون إنشاء ازدواجية.
- الملف الأكاديمي يجمع مواد الطالب واختباراته بصورة صحيحة.
- لوحة القيادة تطبق فلاتر الصف والمادة وتبني الخريطة الحرارية.
- نموذج الاستيراد الموحد الجديد يقرأ 4 اختبارات و12 سجل اختبار لعينة 3 طلاب دون عمود معلم.
- إعادة الاستيراد لا تضاعف النتائج، وتحديث الشعبة لا يفقد الدرجة.
- استمرار التراجع عن الاستيراد والتعديلات اليدوية مع الحفاظ على الاختبارات الأخرى.
- اختبار تصدير XLSX وإعادة استيراده مع حفظ الأرقام والحالات والمعلمين التاريخيين والشعب.
- تجميع 100,000 سجل في اختبار Node مع الحفاظ على الإجمالي؛ آخر تشغيل معزول استغرق قرابة 457ms (الزمن إرشادي ويتغير حسب الجهاز).

ملاحظات منهجية:
- اختبارات المنطق تشغّل كود التطبيق الفعلي في Node مع استبعاد Bootstrap الخاص بالمتصفح.
- اختبارات السحابة تستخدم محاكي ردود SDK وتتحقق من revision/conflict/retry/archive RPC وعدم الرجوع لتخزين النتائج في المتصفح.
- اختبارات البنية تفحص شجرة عناصر الواجهة دون متصفح حقيقي.
- JavaScript النهائي يخضع لفحص syntax أثناء البناء وبعده.
- لا ندّعي هنا اختبارًا بصريًا فعليًا داخل Chrome/Edge؛ بيئة الاختبار الحالية تمنع تنقل المتصفح الآلي المحلي. يوصى بمراجعة بصرية سريعة بعد الرفع على GitHub Pages.
