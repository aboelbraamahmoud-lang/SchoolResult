1. إنشاء حساب دخول للمرة الأولى
افتح: https://supabase.com/dashboard/project/mzrepavyiaceedmuvfbf/auth/users
اختر Add user ثم Create new user.
أدخل بريدك وكلمة مرور قوية من اختيارك، وفعّل Auto Confirm User، ثم أنشئ المستخدم.
حساب البرنامج مستقل عن حساب الدخول إلى لوحة Supabase؛ لا تضع كلمة مرور حساب Supabase تلقائيًا في البرنامج.
لم يُنشأ حساب دخول نيابة عنك، ولا توجد كلمة مرور افتراضية في الحزمة.
إذا نسيت كلمة المرور، يدير مالك المشروع استعادة الوصول من صفحة المستخدمين؛ لا تحذف المستخدم صاحب البيانات.

2. تشغيل البرنامج
فك الضغط كاملًا، ثم افتح index.html أو تشغيل-البرنامج.bat في Chrome أو Edge حديث.
يجب بقاء الملفات معًا، بما فيها supabase.js.
سجّل الدخول بالبريد وكلمة المرور اللذين أنشأتهما للبرنامج.
ستظهر خيارات قاعدة فارغة أو استعادة نسخة JSON أو بيانات تجريبية.
لا يحتاج المستخدم إلى تثبيت Node أو Python؛ يحتاج الإنترنت للوصول إلى السحابة.

3. نقل بياناتك من الإصدار المحلي
افتح نسختك المحلية القديمة قبل استبدالها.
من «النسخ والأرشيف» نزّل «نسخة شاملة مع الأرشيف» في الإصدار 6.4، أو نسخة JSON عادية للإصدارات السابقة.
افتح الإصدار السحابي وسجّل الدخول ثم اختر «استعادة نسخة JSON» وحدد النسخة.
انتظر رسالة نجاح الاستعادة والحفظ، ثم راجع المدرسة وعدد السجلات والأرشيف.
النقل يدوي باختيار ملفك، ولم تُرفع أي نتائج حقيقية من جهازك تلقائيًا.

4. أين تُحفظ البيانات؟
النتائج والمعلمون والإعدادات والتقارير وسجل المراجعة والأرشيف تُحفظ في قاعدة Supabase، داخل حساب الدخول.
افتح البرنامج من جهاز آخر وسجّل الدخول بالحساب نفسه لترى بياناتك.
لكل حساب قاعدة خاصة به؛ إنشاء حساب ثانٍ لا يمنحه بيانات الحساب الأول تلقائيًا.
المتصفح يحتفظ بجلسة الدخول أثناء استخدامه؛ لا يعتمد هذا الإصدار على المتصفح لحفظ النتائج.
النسخ الدائمة لا تُحذف عند تدوير آخر عشر نقاط استعادة، ويمكن تنزيل نسخة شاملة إلى جهازك.

5. انقطاع الإنترنت وتعارض الأجهزة
لا تعتبر التعديلات محفوظة إلا بعد ظهور «محفوظ سحابيًا».
عند انقطاع الاتصال تبقى التعديلات في الصفحة المفتوحة فقط؛ لا تغلقها. أعد الحفظ أو نزّل نسخة JSON.
تغيير بياناتك على جهازين قد يولد تعارضًا. نزّل نسخة النافذة الحالية ثم حمّل أحدث نسخة، أو اعتمد نسختك صراحةً بعد حماية النسختين.
البرنامج لا يدمج تعديلات الجهازين تلقائيًا؛ يمنع الاستبدال الصامت بالتحقق من رقم الإصدار.
التحديثات من جهاز آخر تُقرأ عند تحميل البرنامج أو اختيار تحميل أحدث نسخة؛ ليست مشاركة فورية لحظية.

6. الاستضافة
يمكن فتح ملفات البرنامج على الكمبيوتر مع اتصال الإنترنت، أو رفع ملفات الواجهة إلى استضافة HTTPS ثابتة.
لا يوجد رابط موقع منشور في هذه الحزمة؛ رابط Supabase أعلاه هو لوحة إدارة قاعدة البيانات.
لم تُستخدم مفاتيح إدارية سرية في الواجهة. المفتاح المنشور عام، والوصول إلى النتائج يحتاج جلسة دخول وسياسات ملكية.

7. التكلفة
أداة Supabase أعادت عند الإنشاء تكلفة 0 دولار شهريًا للمشروع.
راجع حدود خطتك وحالة المشروع من لوحة Supabase عند زيادة الاستخدام؛ لا تعني هذه القيمة سعة غير محدودة.

8. تحسينات الإصدار 6.7
قائمة الأرشيف أصبحت خفيفة ولا تُنزّل بيانات النسخ الكاملة عند فتح البرنامج؛ تُجلب النسخة فقط عند العرض أو التنزيل أو الاستعادة.
الحفظ التلقائي يجمع التعديلات المتتابعة قبل الإرسال لتقليل عمليات الكتابة غير الضرورية.
تظهر حالة الاتصال الآن رقم المراجعة وآخر وقت حفظ مؤكد.
أُغلقت صلاحيات قاعدة البيانات الزائدة، ومُحدّث Windows يرفض الرجوع إلى إصدار أقدم.
يوصى من لوحة Supabase بتفعيل Leaked Password Protection ضمن إعدادات Auth لزيادة حماية كلمات المرور.
