# SchoolResult — مرصد النتائج المدرسية

الإصدار السحابي الحالي: **6.9.11**

منصة تحليل وإدارة نتائج مدرسية مرتبطة بـ Supabase، وتشمل:
- إدارة الصفوف والشعب والمواد والمعلمين والتكليفات التدريسية.
- ربط نتائج المواد تلقائيًا بالمعلم من قاعدة الهيكل الأكاديمي.
- منسق مادة محفوظ مع المادة ويظهر تلقائيًا في التقارير.
- ملف أكاديمي متكامل للطالب.
- لوحة قيادة تنفيذية برسوم اتجاه، مقارنة الصفوف، ترتيب المواد، جاهزية التقارير، الخريطة الحرارية ومؤشرات الجودة.
- تقارير PDF/طباعة وExcel، أرشيف سحابي، نقاط استعادة، وسجل مراجعة.

## التشغيل
افتح `index.html` عبر خادم ويب أو GitHub Pages. ملفات التشغيل الأساسية:
`index.html`, `app.js`, `style.css`, `supabase.js`, `moehe.png`.

## المصدر
المجلد `source/` يحتوي خدمات قابلة للصيانة، patches، الاختبارات، وبناء الإصدار.

## التحقق
الملف `checksums.sha256` يحتوي بصمات ملفات الإصدار، و`update-manifest.json` يحتوي بصمات ملفات التحديث الجزئي.

## تقارير 6.9.11
- مقارنة المواد: بيان نسب النجاح وبيان نسب التحصيل الأكاديمي لكل صف دراسي، الشعب صفوف والمواد أعمدة.
- تحليل المستويات: فوق المتوسط / في المتوسط / تحت المتوسط.
- إحصائية نتائج القسم: الصفوف والشعب والمعلمون والحضور والنجاح والتحصيل.
- أسماء منسقي المواد تُسحب من قاعدة البيانات الأكاديمية تلقائيًا.
- تقرير الطلاب ضمن نسبة: ملخص بصري، أشرطة أداء، مستوى متابعة وخطة دعم.
- مقارنة اختبارين: القيمة المضافة/المنقوصة ملوّنة بوضوح مع اتجاه الأداء.

- رأس التقرير أصبح مضغوطًا ومتوازنًا بحيث لا تستحوذ مربعات المدرسة/العام/الاختبار/المادة على مساحة زائدة.
- إضافة هوية وزارة التربية والتعليم والتعليم العالي وشعارها في رأس التقارير، مع إبقاء شعار المدرسة مستقلًا عند تفعيله.
- تحويل بيانات السياق إلى شرائط صغيرة أفقية ومنع تمددها الرأسي غير الضروري في الطباعة والمعاينة.

## واجهة 6.9.11
- قائمة جانبية أكثر فخامة بتدرجات وإضاءة دقيقة، مع رأس ثابت ومضغوط للشعار والبحث فقط.
- تمرير واحد للقائمة الجانبية كاملة، مع مجموعات تنقل أوضح وحالة نشطة أكثر بروزًا.
- لوحة قيادة تنفيذية مطورة بمؤشرات قرار سريعة، رسم توزيع ناجح/راسب، واتجاهات أداء في أعلى الصفحة.
- نظام بصري موحد لجميع التقارير: رؤوس رسمية، بطاقات سياق، جداول محسنة، أشرطة أداء وإجماليات مميزة.
