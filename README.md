# مرصد النتائج المدرسية — SchoolResult

**الإصدار الحالي: 6.10.36 (13 أكتوبر 2026)**

منصة ويب لإدارة وتحليل نتائج الطلاب، وتقارير الأقسام والمعلمين، ومراجعة الدرجات، وشهادات الطلاب، مع نسخة Windows مستقلة مبنية من المصدر نفسه.

## الوظائف الأساسية

- استيراد نتائج الاختبارات المتعددة وملفات Excel ذات الشعب المتعددة، مع مصالحة ومراجعة قبل الاعتماد.
- فصل نتائج طلاب الدعم الإضافي (مثل `07/ESE`) عن التعليم العام وعدم تحويل الغياب أو عدم الرصد إلى صفر.
- إدارة الصفوف والشعب والمواد والمعلمين والتكليفات، وربط النتائج بالإسنادات المعتمدة.
- لوحات تحليل، مقارنة التقييمات، نسب النجاح والتحصيل، الجودة والغياب والقيمة المضافة.
- طباعة بيان درجات الطالب والتقارير الأكاديمية والسلوكية، واستيراد بيانات هذه الشهادات من Excel.
- تصدير قوالب Word الرسمية للمعلمين والأقسام وخطط تحسين الأداء والشهادات، دون إرسال أسماء الطلاب إلى خدمة توليد خارجية.
- إدارة المستخدمين والصلاحيات عبر Supabase، والأرشيف ونقاط الاستعادة، والتقارير والنسخ الاحتياطية.

## رفع المشروع وتشغيله

**حزمة GitHub الكاملة** تحتوي الملفات مباشرة في جذر ZIP. ارفع جميع محتويات الحزمة إلى **جذر المستودع**، مع الحفاظ على أسماء المجلدات `source/` و`desktop/` و`assets/` و`.github/`؛ لا ترفع مجلدًا أبًا إضافيًا فوقها.

ملفات تشغيل الموقع الرئيسية:

- `index.html`, `app.js`, `style.css`, `supabase.js`, `moehe.png`, `version.json`
- `assets/word-reference.js`, `assets/word-improvement.js`, `assets/word-behavior.js`
- ملفات قوالب Excel الثلاثة في جذر المشروع.

تقوم عملية نشر Vercel عبر `vercel.json` و`source/scripts/vercel-static.cjs` بتجهيز `public/` آليًا. يجب نشر مجلد `assets/` معها، وإلا لن يعمل تصدير Word الذي يحمّل قوالبه عند الطلب. تعتمد المنصة على إعداد Supabase موجود مسبقًا مع RLS وصلاحيات ملائمة؛ لا تُلصق مفتاح `service_role` في الواجهة.

**لا توجد حاجة إلى مسح بيانات الطلاب أو إعادة استيرادها بسبب هذا التحديث.** احتفظ بنسخة احتياطية قبل ترقية الإنتاج أو تغيير إعدادات Supabase.

## بنية المشروع

| المسار | وظيفته |
|---|---|
| `source/base/` | أساس التطبيق الذي تُطبّق عليه ترقيعات البناء؛ لا تحذفه |
| `source/src/` | وظائف وتقارير واختبارات ومولدات المستندات؛ المصدر النهائي للصيانة |
| `source/src/patches/` | التعديلات المُطبقة على التطبيق الأساسي |
| `source/tests/` | الاختبارات الآلية للوظائف والأمان والتقارير |
| `source/db/`, `supabase/` | SQL والترحيلات اللازمة للتكامل السحابي |
| `.github/workflows/` | اختبارات CI، بناء Windows وفحص اتصال Supabase الدوري |
| `desktop/` | مصدر نسخة Windows وخادمها المحلي |
| `assets/` | قوالب Word الرسمية المؤجّلة التحميل |
| `public/`, `desktop/web/` | مخرجات بناء مولّدة **لا تحفظها في GitHub** |

## البناء والاختبارات

على Node.js 22 أو نسخة متوافقة:

```bash
npm --prefix source install --no-audit --no-fund
npm run verify
npm --prefix desktop run verify
```

أوامر مفيدة:

```bash
npm run build                # بناء app.js وstyle.css من المصدر
npm run test                 # اختبارات وظائف النظام
npm run release              # إنشاء بصمات الملفات وإصدار النشر
npm run test:release         # التحقق من سلامة ملفات النسخة
npm --prefix desktop run sync:web  # تجهيز ملفات Windows من جذر الويب
```
