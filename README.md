# SchoolResult — مرصد النتائج المدرسية

الإصدار الحالي: **6.9.17**

هذه هي الحزمة الكاملة النظيفة للمشروع: ملفات التشغيل المنشورة، المصدر القابل للصيانة، اختبارات الجودة، تعريفات قاعدة البيانات، أدوات التحديث، وقوالب الاستيراد. لا تحتوي على حزم أو ملفات تفعيل أو نتائج اختبارات تخص إصدارات سابقة.

## ملفات التشغيل
- `index.html`
- `app.js`
- `style.css`
- `supabase.js`
- `moehe.png`
- `version.json`
- `update-manifest.json`
- `checksums.sha256`

## المصدر
المجلد `source/` هو مصدر التطوير الحالي. التطبيق ما زال مبنيًا فوق bundle أساس داخل `source/base/app.js` مع خدمات وطبقات صيانة داخل `source/src/`. لا تعدّل `app.js` النهائي يدويًا؛ عدّل المصدر ثم أعد البناء.

## البناء والاختبار
من داخل `source/`:
```bash
node --expose-internals build.cjs
node --expose-internals tests/regression.cjs
node --expose-internals tests/report-logic-current.cjs
node --expose-internals tests/cloud.cjs
node --expose-internals tests/structure.cjs
node release.cjs
node tests/release.cjs
```

## منطق التقارير الحالي
- التقارير العادية تربط المعلم بمادته الفعلية ولا تعرض «كل المواد» لمعلم محدد.
- المعلم الذي يدرّس أكثر من مادة يحصل على صفحة مستقلة لكل مادة.
- «كل المعلمين» يرتب الصفحات حسب المادة ثم معلميها.
- مقارنة المواد: صفحة عرضية لكل صف دراسي، وبيان مستقل للنجاح وبيان مستقل للتحصيل؛ تحت كل مادة `اسم المعلم | النسبة`.
- إحصائية نتائج القسم: صفحة عرضية لكل صف؛ تحت كل مادة `اسم المعلم | نسبة النجاح | نسبة التحصيل`.
- تحليل المستويات: فوق المتوسط / في المتوسط / دون المتوسط.
- مقارنة اختبارين لا تخلط مواد مختلفة، والقيمة المضافة أو المنقوصة تظهر بصريًا.

## الاستضافة
يمكن نشر ملفات الجذر مباشرة على GitHub Pages أو أي استضافة HTTPS ثابتة.

## قاعدة البيانات
`source/db/schema.sql` مرجع إنشاء بيئة جديدة، ومجلد `source/db/migrations/` يحتوي ترحيلات قاعدة البيانات اللازمة للمشروعات القائمة. لا تضع `service_role` أو أي Secret في الواجهة.
