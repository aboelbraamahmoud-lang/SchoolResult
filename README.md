# مرصد النتائج المدرسية — SchoolResult

**الإصدار الأساسي النظيف: 6.9.24**  
تاريخ الإصدار: 2026-10-08

هذه الحزمة هي نقطة البداية الرسمية للمشروع بعد تنظيف مستودع GitHub. لا تحتوي على إصدارات قديمة، تقارير اختبار محفوظة، نسخ Desktop مكررة، أو ملفات بناء مؤقتة.

## بنية المستودع

- ملفات الجذر (`index.html`, `app.js`, `style.css`, `supabase.js`) هي نسخة الويب الجاهزة للنشر.
- `source/` هو السورس القابل للصيانة، الاختبارات، وملفات SQL.
- `desktop/` يحتوي مصدر Electron فقط. مجلد `desktop/web/` **مولد تلقائيًا** ولا يُحفظ في GitHub.
- `.github/workflows/build-windows-setup.yml` يبني Windows Setup ويختبر أن التطبيق لا يغلق فور التشغيل.
- `.github/workflows/supabase-keepalive.yml` ينفذ قراءة صحية دورية آمنة باستخدام المفتاح العام فقط.

## دورة التطوير المعتمدة

1. التعديل داخل `source/`.
2. تثبيت اعتماديات السورس مرة واحدة: `npm --prefix source ci`.
3. تشغيل `npm run verify`.
4. رفع الملفات الناتجة والسورس إلى GitHub.
5. عند الحاجة لنسخة Windows: **Actions → Build Windows Setup → Run workflow**.

## الملفات المولدة التي لا تُرفع يدويًا

- `source/node_modules/`
- `source/tests/output/`
- `desktop/node_modules/`
- `desktop/dist/`
- `desktop/web/`

## قاعدة البيانات

ملفات Supabase وRLS وSQL migrations موجودة تحت `source/db/`. لا تستخدم الواجهة الأمامية `service_role`.
